# Enchant-expansion（附魔拓展）

> 由 AI 和朋友一起制作的 Minecraft 附魔扩展模组。
>
> **当前版本：1.3.8 beta 2.5** · **Minecraft 1.20.1** · **Forge 47.4.10**

本模组围绕自定义附魔、特殊装备、少女实体和探索内容展开，包含战斗、远程、工具、农业、移动、装备强化、剧情互动等系统。具体数值以游戏内效果和配置文件为准。

## 安装与兼容

- 游戏版本：Minecraft Java Edition 1.20.1
- 模组加载器：Minecraft Forge 47.x，本版本开发与测试环境为 Forge 47.4.10
- 模组 ID：`enchantment_expansion`
- 本模组支持客户端和服务端；多人游戏时客户端与服务端都应安装相同版本。
- 配置文件：`config/enchantment_expansion-common.toml`。附魔数值、部分技能参数、少女系统和特殊物品的可调选项均以实际配置内容为准。
- 推荐安装 **IMBlocker**，用于减少输入法与游戏按键输入之间的冲突。

## 核心内容

### 自定义附魔

附魔的获取方式包括附魔台、村民交易、钓鱼、结构宝箱、合成配方和成就奖励等。部分附魔属于宝藏附魔，只能通过指定结构宝箱或交易获得；互斥关系以游戏内附魔规则和终界之书为准。

#### 弓、弩与投射物

| 附魔 | 主要效果 |
|------|----------|
| 云来弓法 / 古·云来弓法 | 提升拉弓速度；古·云来弓法同时提高箭矢速度，属于稀有版本 |
| 琉璃冰魄箭 | 强化蓄力箭矢，命中后造成范围伤害并牵引敌人 |
| 迅捷之弩 | 提高弩箭魔法伤害并加快弩的装填速度，最高 IV 级 |
| 爆破箭矢 | 箭矢命中后产生不破坏地形的小型爆炸，最高 III 级 |
| 贯穿链条 | 箭矢命中后弹射至附近敌人，最高 III 级 |
| 末影箭 | 箭矢命中方块或实体后将射手传送至命中位置，带有冷却 |
| 狙击 | 箭矢飞行距离越远伤害越高，存在伤害上限 |
| 雷电之戟 | 投掷三叉戟命中实体时召唤闪电；等级越高，天气和维度限制越少 |

#### 剑、斧与近战武器

| 附魔 | 主要效果 |
|------|----------|
| 云来剑法 / 古·云来剑法 | 提升攻击速度、攻击距离和伤害，并有概率发射贯穿剑气 |
| 千破·青溟剑 | 造成额外魔法伤害，最高 V 级 |
| 终末将至 | 大幅提高武器伤害并缩短攻击冷却，属于高强度宝藏附魔 |
| 拂晓 | 通过击杀成长，提供暴击、处决、吸血、溅射和连击爆发等效果 |
| 兵长的回声 | 攻击叠加标记，达到层数后造成基于生命值的魔法伤害 |
| 熵增 | 叠加熵标记，满层后造成真实伤害并扩散 |
| 星火不灭 | 叠加星火并造成生命值比例伤害，目标死亡后可向附近敌人扩散 |
| 嗜血 | 攻击命中怪物时恢复生命值，带有冷却时间 |
| 攫取 | 有概率打落敌方装备 |
| 强夺 | 提高稀有战利品和怪物装备的掉落收益 |
| 蓄积 | 长按右键蓄力，蓄满后下一次攻击造成额外伤害和击退 |
| 画饼充饥 | 攻击命中生物时恢复饥饿值和饱和度 |
| 经验馈赠 | 击杀怪物时额外获得经验 |
| 难度馈赠 | 根据当前游戏难度为武器提供不同强度的攻击加成 |

#### 工具与耐久

| 附魔 | 主要效果 |
|------|----------|
| 自动冶炼 | 矿石直接掉落冶炼后的成品，并可随等级提高额外掉落概率 |
| 匠心传承 | 记忆挖掘过的方块，同类方块越挖越快，并有概率额外掉落 |
| 无中生有·重制 | 挖掘石质方块时有概率获得矿物；剪刀采集树叶时保留金苹果掉落 |
| 连锁挖掘 | 按住 `~` 键连锁破坏同类型方块，范围随等级扩大 |
| 耐久强化 | 提高最大耐久并有概率免除耐久消耗，最高 III 级 |
| 自动修复 | 持有或穿戴相关物品时定期恢复耐久，属于宝藏附魔 |
| 中国制造 | 融合耐久、自动修复和匠心传承效果的单级附魔 |

#### 移动、生存与农业

| 附魔 | 主要效果 |
|------|----------|
| 风踏涟漪 | 提升陆上移动能力，并允许在水面快速移动 |
| 优雅猫步 | 提供轻盈、灵活的移动效果 |
| 飞轮效应 | 按绑定键朝准心冲刺，冲刺期间可穿透实体并暂时免伤 |
| 深海的涟漪 | 按住 Shift 加鼠标滚轮调节水中游泳速度 |
| 幽匿行者 | 隐匿行动，不触发幽匿感测体、尖啸体和相关振动 |
| 温度恒定 | 免疫冰冻和高温伤害 |
| 坠落缓冲 | 降低摔落伤害，并在高处落地时震退附近敌人 |
| 疾跑节能 | 降低或抵消疾跑带来的额外饥饿消耗，最高 II 级 |
| 春华秋实 | 锄头右键范围开垦，或收获成熟作物并原地补种 |
| 万物回春 | 消耗骨粉，对范围内未成熟作物进行催熟 |
| 丰饶之息 | 加速附近作物生长，并提高相关收获收益 |

> 附魔的具体等级、数值、获取方式和冲突关系可能随版本与配置变化。安装 Patchouli 后，可在游戏内通过「终界之书」查看更完整的说明。

## 特殊物品

### 星星系列

星星类物品可直接手持或通过 Curios 饰品栏嵌入装备。部分星星拥有独立的配方、结构获取方式或成就条件。

- **终界之星**：提供飞行、伤害减免、经验等级伤害加成，并能在危险情况下提供虚空救援。
- **海洋之星**：提供水下挖掘、水中移动和呼吸能力，并使守卫者对持有者保持中立。
- **生命之星**：提高生命上限、回血能力，并降低饥饿和饱和度消耗。
- **虚空之星**：免疫摔落与虚空伤害，坠入虚空时尝试将玩家送回出生点。
- **星辉之星**：夜间提供夜视和移动速度加成，并提高击杀经验收益。
- **晨曦之星**：通过击杀积累晨光，满层后进入「晨曦」状态，获得伤害、暴击、移速和恢复加成。

### 武器与装备

- **人权剑**：击败凋零后获得的特殊武器，拥有内置附魔和主动技能「人的意志」。
- **人权剑·星火永燃**：与星火相关系统联动的强化版本，拥有额外的保命和攻击效果。
- **湮灭之镰**：可释放直线剑气并积累湮灭能量，使用按键释放范围技能。
- **洛红雨**：自带高等级千破·青溟剑效果，命中目标后施加凋零和虚弱。
- **星尘手绳**：提供怪物感知范围、减伤和攻击方面的特殊效果。
- **永恒图腾**：拥有耐久次数的保命道具，抵挡致命伤害后提供短时间增益。
- **强化卷轴**：在铁砧中与附魔装备或附魔书使用，可提升已有附魔；附魔满级时会尝试添加兼容附魔。

## 少女实体与探索

模组加入了丧尸娘、溺尸娘和幸存者少女三种实体，并包含生成、驯服、互动、装备、背包、睡眠、送礼、好感阶段和剧情日记等内容。

- 丧尸娘和溺尸娘拥有对应的自然生成环境与行为逻辑。
- 幸存者少女拥有独立的生成和互动内容。
- 少女可以进行驯服、跟随、休息、装备和物品交互。
- **归乡铃**可以召回主人名下的已驯服少女，包括未加载区块中的个体。
- 世界中会生成丧尸娘营地，并配套营地战利品和位置记录。
- 可使用 `/ee locate camp` 定位营地；具体命令权限和生成概率以游戏规则及配置为准。
- **无名诗笺**等剧情物品会在获得时解锁终界之书中的叙事内容。

丧尸娘材质由 Wildcanyon 提供，详见下方致谢部分。

## 游戏内图鉴与配置

安装 Patchouli 后，模组会提供「终界之书」，用于查看：

- 附魔效果、等级与获取方式
- 特殊物品和星星系列的效果
- 少女实体与相关内容
- 附魔冲突和部分操作说明

所有可配置项目位于：

```text
config/enchantment_expansion-common.toml
```

配置修改后通常需要重新进入世界或重启游戏才能完全生效。不同版本的配置项目可能会变化，请以当前版本自动生成的配置文件为准。

## 快速测试

以下命令适用于创造模式或拥有管理员权限的测试环境：

```text
/summon enchantment_expansion:zombie_girl
/summon enchantment_expansion:drowned_girl
/summon enchantment_expansion:survivor_girl
/ee locate camp
/give @s enchantment_expansion:home_bell
/give @s enchantment_expansion:enhancement_scroll
```

附魔测试可使用创造模式物品栏、附魔台、村民交易或 `/enchant` 命令。部分宝藏附魔和特殊物品有专属获取条件，直接使用命令生成仅用于功能测试。
