## 📜 附魔书效果一览

> 所有附魔的数值均可在 `config/enchantment_expansion-common.toml` 中调整；获取方式与获取难度因附魔而异。

### 🏹 弓类附魔

| 附魔 | 效果 |
|------|------|
| 云来弓法| 云来弓术的基础心法，仅提升拉弓速度（蓄力约 0.45 秒），适合入门修习 |
| 古·云来弓法| 传承自古老云来宗门的弓术（已经失传），大幅提升拉弓速度与箭矢飞行速度（蓄力约 0.5 秒、箭速 3.5 倍），仅可通过宝箱/村民交易获得 |
| 琉璃冰魄箭| 冰晶之力注入箭矢：蓄力速度减半、母箭以 3.2 倍速度飞行，射出时立即散射 12 支子箭，命中后爆发范围伤害并牵引周围敌人 |

> ⚠️ 冲突规则：云来弓法 / 古·云来弓法 / 琉璃冰魄箭，三者互斥，不可同时附魔在同一把弓上。

## 💎 三大物品介绍

### 终界之星（End Star）

击败末影龙后，在末地返回传送门上方出现。手持时被动生效：

- ✈️ **创造模式飞行**——生存模式手持亦可飞行
- 🛡 **80% 伤害减免**（单次伤害先限伤至 10 点）
- ⚔ **经验等级伤害加成**——每 10 级 +100%，上限 +1000%（100 级）
- ⛏ **免疫挖掘惩罚 / 免疫移动减速**（移除挖掘疲劳与缓慢效果）
- ✨ 手持或掉落时环绕紫色附魔粒子

### 人权剑（Sword of the Free Will）

击败凋灵后掉落，无法合成。被动与主动兼备：

- 🛡 **被动**：护甲 +10、伤害减免 25%，内置锋利 X / 亡灵杀手 X / 击退 II / 拂晓 I
- ⚡ **主动技能【人的意志】**：右键激活，10 分钟内伤害 +150%，每次攻击 90% 概率降下闪电（消耗 25% 生命、冷却 15 分钟）

### 海洋之星（Ocean star）

在海洋神殿顶部的宝箱中获得（每个神殿仅一个，100% 生成）。手持时被动生效：

- ⛏ **水下挖掘免疫**——不受水下挖掘惩罚，水下挖掘速度提升至 1.25 倍
- 🌊 **免疫水流减速**——水中移动接近陆地速度，不受水流推力影响
- 🫁 **水下无需呼吸**——不扣氧气，免疫溺水窒息伤害
- 🐟 **守卫者中立化**——守卫者/远古守卫者不主动攻击持有者（被攻击后正常反击）
